# Contributing

Thank you for improving Project Scaffolder.

1. Fork the repository and create a focused branch.
2. Use Python 3.10+ and install with `python -m pip install -e . pytest`.
3. Run `python -m pytest -q` and `python -m compileall -q src tests`.
4. Add tests for behavior changes. Templates must generate runnable, minimal projects and must not contain secrets, network calls, or destructive scripts.
5. Keep changes small and document user-visible behavior.
